# FlipMind

FlipMind is a memory card game website made for CST2120 Web Applications and Databases, Coursework 1.

**Play it here:** https://erionsehou-crypto.github.io/FlipMind/

## Features

- Register and log in (accounts are stored in the browser with localStorage)
- A memory card game built with Phaser 3, with several levels
- A rankings page showing the best scores

## Built with

- HTML, CSS and JavaScript (ES modules)
- [Phaser 3](https://phaser.io/), loaded from a CDN

## Running it locally

The site uses JavaScript modules, so it must be served by a web server rather than opened from a file. For example, open the folder in VS Code and use Live Server, or run:

```
python3 -m http.server
```

Then open http://localhost:8000.
